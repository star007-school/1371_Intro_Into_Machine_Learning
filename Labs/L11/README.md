# Lab 11 – Hyperparameter Tuning and AutoML

## Objective

The objective of this lab was to improve machine learning model performance by optimizing hyperparameters and to explore how Automated Machine Learning (AutoML) can simplify the model selection and tuning process.

## What I Did

In this lab, I used **GridSearchCV** and **RandomizedSearchCV** to tune the hyperparameters of a **Random Forest Classifier** trained on the Iris dataset. I compared the advantages and tradeoffs of exhaustive grid search versus random search and identified the best-performing model configuration. I also explored **AutoGluon**, an AutoML framework that automatically trains, evaluates, and compares multiple machine learning models to identify the strongest performer.

## What I Learned

This lab demonstrated how selecting the right hyperparameters can significantly improve model performance. I learned the differences between Grid Search and Random Search, when each approach is appropriate, and how AutoML can automate much of the model development process by testing multiple algorithms and configurations with minimal manual effort.
