# Lab 5 – Data Preparation and Preprocessing

## Objective

The objective of this lab was to learn and apply essential data preprocessing techniques used to prepare raw data for machine learning models. This included handling missing values, encoding categorical variables, and scaling numerical features.

## What I Did

In this lab, I worked with the Titanic dataset and completed several common preprocessing tasks. I replaced missing values in the **Age** column using median imputation, converted categorical features such as **Sex** and **Embarked** into numerical values using one-hot encoding, and standardized the **Age** and **Fare** features with `StandardScaler`. I also answered questions about why these preprocessing steps are important before training machine learning models.

## What I Learned

This lab demonstrated that data preparation is one of the most important steps in the machine learning workflow. I learned how to handle missing data, convert categorical variables into a machine-readable format, and scale numerical features so that models can perform more effectively. These techniques help improve data quality and model performance.
