# Lab 4 – Exploratory Data Analysis (EDA)

## Objective

The objective of this lab was to learn how to perform Exploratory Data Analysis (EDA) by using summary statistics and visualizations to better understand a dataset before building a machine learning model.

## What I Did

In this lab, I explored the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn. I analyzed summary statistics and created several visualizations to identify patterns and relationships within the data. I examined how factors such as passenger class, gender, age, port of embarkation, and fare related to survival rates. I also completed additional experiments by creating my own visualizations and interpreting the results.

## What I Learned

This lab demonstrated the importance of understanding data before training a machine learning model. I learned how exploratory data analysis can reveal trends, relationships, and potential issues that may influence model performance. Through data visualization, I gained a better understanding of how different passenger characteristics affected survival on the Titanic.
