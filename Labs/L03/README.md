# Lab 3 – Machine Learning Workflow and Types of Learning

## Objective

The objective of this lab was to understand the complete machine learning workflow and explore the different types of machine learning, including supervised, unsupervised, and reinforcement learning. This lab also introduced the process of building and evaluating a machine learning classification model.

## What I Did

In this lab, I explored the Wine dataset using Python and performed exploratory data analysis to better understand the data before training a model. I followed the complete machine learning workflow by preparing the data, selecting features, splitting the dataset into training and testing sets, training classification models, evaluating their performance, and interpreting the results. I also learned about different types of data used in machine learning and practiced building my own classification model.

## What I Learned

This lab helped me understand the importance of following a structured machine learning workflow. I learned the differences between supervised, unsupervised, and reinforcement learning, how to prepare data for modeling, and how to evaluate model performance using common machine learning techniques. I also gained experience working with real datasets and interpreting model results.
