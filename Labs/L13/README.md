# Lab 13 – Building Machine Learning Pipelines

## Objective

The objective of this lab was to learn how to build professional and reproducible machine learning workflows using **scikit-learn Pipelines**. I explored how pipelines simplify preprocessing and model training while helping prevent common issues such as data leakage.

## What I Did

In this lab, I revisited the Titanic dataset and compared a traditional machine learning workflow with a pipeline-based approach. I used `make_pipeline` and `make_column_transformer` to combine preprocessing steps, including imputing missing values, encoding categorical features, scaling numerical features, and training a **Random Forest Classifier**. I then evaluated the model's accuracy and reflected on the advantages of using pipelines in machine learning projects.

## What I Learned

This lab demonstrated how machine learning pipelines create cleaner, more organized, and reproducible code. I learned that pipelines help automate preprocessing and model training while reducing the risk of **data leakage**, ensuring that transformations are applied consistently to both training and testing data. This approach reflects professional best practices for developing machine learning models.
